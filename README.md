# Chamados de TI

Criar um dashboard dinâmico, interativo a partir da planilha em anexo. Organizar o dashboard de acordo com as novas cores e informações da planilha 1; criar e nomear planilhas mensais, exemplo a planilha 1 passa a ser o mês de setembro, adicionar até dezembro de 2026; todas as planilhas precisam terem as mesmas configurações; colocar automaticamente as cores conforme a prioridade digitada; adicionar um novo status: "Cancelado", conforme cor da planilha 1; criar no dashboard um gráfico pizza interativo com os problemas mais recorrentes e departamentos que mais abrem chamados; o dashboard precisa puxar automaticamente todas as informações da planilha mensal; adicionar regras para pausar automaticamente o SLA aos finais de semana (sábado, domingo), feriados, férias coletivas, férias, viagens a serviço, normais e atestados médicos, horário de atendimento nos dias da semana de segunda a sexta feira; criar uma planilha com as regras e prioridades a serem editadas conforme necessidade do gestor; o dashboard precisa puxar todas as regras automaticamente; colocar no menu superior do dashboard todas as opções necessárias para facilitar o trabalho do gestor; usar todos os mecanismos possíveis para facilitar as apresentações dos dados com clareza e fidelidade. Vou anexar a planilha já com os dados atualizados para você organizar e configurar conforme pedi. Criar um formulário intuitivo, simples para abrir chamado de TI, com todas as opções e informações necessárias para o usuário não ter dificuldades, obrigar o usuário a informar o local (setor, sala, andar, pavilhão, bloco, etc) onde está o problema. Faça menus bem visíveis da planilha de chamado, do dashboard, das regras e prioridades. Organize a página principal da forma que você achar melhor, mais atraente, use as cores do GOOGLE para criar o site no geral
